# IOC and Telemetry Schema

This document outlines the standardized data schemas adopted across Sentinel-AI for Runtime Telemetry events and Indicators of Compromise (IOCs).

## Telemetry Schema

All events generated by the local sandbox wrapper (`sandbox/local_sandbox.py`) and transmitted over Redis WebSockets conform to the following schema:

```json
{
  "type": "PROCESS_CREATE",
  "severity": "high",
  "timestamp": "2026-05-26T14:30:00.000Z",
  "data": {
    "cmdline": "powershell -enc JABzAD..."
  }
}
```

### Supported Event Types & Severities
- `PROCESS_CREATE` (High): When an external OS-level executable is spawned.
- `EXECUTION` (High): Execution of code or dynamic loading.
- `FILE_WRITE` (Medium): When a file handle is opened with write, append, or create permissions (excluding `.pyc`).
- `SOCKET_CONNECT` (Medium): Outbound TCP/UDP socket connections.
- `DNS_QUERY` (Medium): Hostname resolution requests (ignoring localhost).
- `STATUS_CHANGE` (Info): Status events emitted during the job lifecycle (e.g., `analyzing`, `completed`).
- `EXECUTION_ERROR` (High): Runtime crashes or exceptions raised during dynamic analysis.
- `EXECUTION_TIMEOUT` (High): Raised if the sandbox reaches its execution time limit (default 10s).

## Indicators of Compromise (IOC) Schema

The `ioc_pipeline.py` service consolidates static strings and runtime events into structured IOC records. These are persisted in MongoDB and rendered in the frontend.

```json
{
  "type": "ip",
  "value": "185.11.23.4",
  "source": "Runtime Telemetry",
  "confidence": "High"
}
```

### Supported IOC Types
- `ip`: IPv4 or IPv6 addresses.
- `domain`: Registered hostnames.
- `url`: Full web addresses.
- `sha256` / `md5`: File hashes computed prior to sandbox execution.
- `command`: Suspicious command line arguments (e.g. encoded PowerShell strings).

### Confidence Scoring
- **High**: Derived from verifiable runtime actions (e.g., actual DNS queries, established socket connections, computed static hashes).
- **Medium**: Derived from suspicious, but non-network runtime patterns (e.g., spawning powershell).
- **Low**: Derived from static string extraction (e.g., finding an IP address in the binary text which may just be a false positive or imported library reference).
